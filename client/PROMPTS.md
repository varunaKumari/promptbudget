# Prompts Used in PromptBudget

## AI Summary Generation Prompt

### Purpose
Generate a ~100-word personalized summary paragraph for each audit result. The summary should be specific, cite dollar amounts, and give the user a clear action to take.

### System Prompt
```
You are a financial advisor specializing in AI/SaaS tool optimization for startups and engineering teams. You write clear, concise, actionable summaries.

Your tone is:
- Professional but friendly
- Specific with numbers (always cite dollar amounts)
- Honest — if a company is already well-optimized, say so
- Action-oriented — every sentence should help the reader decide what to do

Never use marketing fluff. Never be vague. Always reference the specific tools and numbers from the audit data.
```

### User Prompt Template
```
Based on the following AI spend audit data, write a personalized ~100-word summary paragraph for the user.

Audit Data:
- Total tools audited: {{toolCount}}
- Current monthly spend: ${{currentSpend}}/month
- Potential optimized spend: ${{optimizedSpend}}/month
- Total monthly savings: ${{monthlySavings}}/month (${{annualSavings}}/year)
- Savings percentage: {{savingsPercent}}%

Per-tool breakdown:
{{toolBreakdown}}

Instructions:
1. Start with the headline finding (total savings opportunity or "well-optimized")
2. Call out the #1 biggest savings opportunity by name
3. If savings > $500/mo, mention that Credex can help capture additional savings through discounted credits
4. If savings < $100/mo, be honest that they're spending well
5. End with one clear next step
6. Keep it to ~100 words. Be specific, cite dollar amounts.
```

### Design Decisions

1. **System prompt as financial advisor**: Framing the AI as a financial advisor (not a tech reviewer) ensures the output focuses on money, not feature comparisons. This matches what a startup founder or engineering manager actually wants to hear.

2. **Explicit instruction to cite dollar amounts**: Without this, LLMs tend to speak in generalities ("significant savings possible"). The explicit instruction forces concrete numbers.

3. **Honesty clause for low-savings cases**: This prevents the AI from manufacturing fake urgency when the user is already spending well. Trust > conversion.

4. **Credex mention gated by threshold**: Only mentioning Credex for >$500/mo savings prevents it from feeling spammy on every result.

5. **Max tokens = 300**: This prevents the AI from writing a wall of text. The ~100-word target plus this limit keeps responses concise.

### What I Tried That Didn't Work

1. **No system prompt**: Without the financial advisor framing, the AI defaulted to a generic tech-reviewer tone with phrases like "there are several areas for optimization." Not actionable enough.

2. **Asking for bullet points**: Bullet-point summaries felt clinical and lost the narrative flow. A single paragraph reads better when shared or screenshotted.

3. **Including all recommendation details in the prompt**: Passing every recommendation's full reasoning made the prompt too long and the output unfocused. The per-tool breakdown with just the top action is the right level of detail.

### Fallback Behavior

If the Anthropic API is unavailable (rate limit, auth failure, network error), the tool falls back to a templated summary generated by `generateTemplatedSummary()` in `lib/audit-engine.ts`. The template follows the same structure: headline finding → top opportunity → next step. It's less nuanced than the AI version but always available.

### Model Choice

Using `claude-sonnet-4-20250514` for the best balance of quality and speed. Opus would be higher quality but slower and more expensive for a free tool. Haiku would be faster but the quality difference is noticeable for a user-facing summary.
